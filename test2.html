SPAR VBA Label Editor

Cette application sert d'interface graphique pour modifier ton générateur d'étiquettes PowerPoint VBA.

Le principe est simple :

  • Tu modifies les paramètres à gauche.
  • La prévisualisation se met à jour.
  • Tu génères le VBA.
  • Tu peux ensuite télécharger le fichier .bas.

Le programme ne modifie pas directement ton fichier PowerPoint. Il génère le code VBA que tu peux ensuite importer dans l'éditeur VBA de PowerPoint.

La prochaine évolution pourra permettre de sélectionner directement chaque élément de l'étiquette et de le déplacer avec la souris.
